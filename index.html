What it does

Built for senior web developers, designers, content teams, and QA reviewers who need evidence on the live page — not another detached scanner.

Inspect & visual QA

Element picker, computed type, contrast, box model, DOM outline, EyeDropper, temporary text edits, and visual stress tests.

Accessibility / ADA / WCAG

axe-core plus supplemental checks. Title II / WCAG 2.1 AA baseline, or a stricter WCAG 2.2 + California forward-looking profile.

California web standards

Maps evidence to the nine design principles. State-only ca.gov checks stay off unless the hostname actually is a state site.

Broken Link Identifier

On-demand scan of same-page fragments and up to 300 HTTP(S) links, with broken, blocked, timeout, and unverified buckets.

Responsive Device Lab

Side-by-side iframe viewports from small phone through wide desktop, with optional synchronized scrolling.

Capture & campaign notes

Full-page PNG, print/PDF, annotation pins, Markdown export, JSON evidence dump, and heuristic campaign analysis.

Install

One click after Tampermonkey is installed. Updates come from this GitHub Pages URL.

  1. Install Tampermonkey for your browser.
  2. Open webdev-command-center.user.js and confirm the install prompt.
  3. Visit any http or https page. Use the floating panel in the lower-right corner.

The Tampermonkey menu also includes Toggle, Run full audit, Open Responsive Lab, and Clear annotations.

Optional AI bridge

webdev-ai-bridge.mjs keeps the OpenAI key on your machine. Node.js 20+ only — no npm packages.

OPENAI_API_KEY="YOUR_KEY" node webdev-ai-bridge.mjs

Health check: http://localhost:8787/health. Default analyze endpoint: http://localhost:8787/analyze.

Limitations

  • Automated scans are evidence, not proof of ADA or WCAG compliance.
  • California requirements vary by entity. State-only rules are not treated as failures on city, county, or private sites.
  • Security checks are page-level heuristics, not a penetration test.
  • Responsive iframes may be blocked by the target site’s framing policy.
